# The Fantasy Attractor Research Program

Repository of the Attractor Framework, developed by Robert Galida, independent researcher, St. Catharines, Ontario, Canada.

The framework prices persistence as excess entropy production under perturbation. Its central parameter is corrective permeability, k = 1/D, where D is attractor depth. The core falsifiable prediction: k is inversely proportional to attractor depth, testable across physical, biological, cognitive, and social systems. All persistent structures are either conservative (the metronomes, the eternal skeleton) or dissipative (the transient dance).

## Honest status

This work is self-published and not peer-reviewed. Claimed results are stated with their evidence; nothing here has passed external review. The framework invites challenge, correction, and collaboration. The program's discipline: check the stove, truth is what can be verified.
